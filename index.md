## Level 0

**Задание:** Подключиться к серверу по SSH.

**Решение:** Использовал команду `ssh level0@10.22.31.60`. Ввел пароль, полученный из условия.

## Level 1

**Задание:** Пароль в скрытом файле внутри inhere.

**Решение:** 
1. Перешел в директорию: `cd inhere`
2. Вывел список всех файлов, включая скрытые: `ls -la`
3. Нашел скрытый файл и прочитал его: `cat .hidden`

## Level 2

**Задание:** Поиск пароля в директории.

**Решение:** Изучил содержимое директории с помощью `ls`, нашел нужный файл и прочитал его командой `cat`.

## Level 3

**Задание:** Найти readme файл и прочитать ключ.

**Решение:** 
1. Воспользовался поиском по файлам: `find . -type f -iname "readme*"`
2. Нашел путь к файлу и прочитал его: `cat ./inhere/readme.txt`

## Level 4

**Задание:** Ключ в архиве, архив в домашнем каталоге.

**Решение:** 
1. Перешел в домашний каталог: `cd ~`
2. Посмотрел список файлов: `ls`
3. Распаковал архив: `tar -xf имя_архива.tar`
4. Прочитал извлеченный файл: `cat имя_файла`

## Level 5

**Задание:** Поиск пароля в большом количестве файлов.

**Решение:** Использовал команды `ls` и `grep` для поиска нужной строки в файлах.

## Level 6

**Задание:** Поиск пароля по заданным параметрам.

**Решение:** Воспользовался командой `find` с нужными флагами для поиска файла по размеру или правам доступа, затем прочитал его через `cat`.
